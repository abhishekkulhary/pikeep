Your Pi backs itself up. You just press start.

PiKeep is a remote control for the backup job on your Raspberry Pi. Choose what to back up, start it or put it on a schedule, watch encrypted snapshots of your photos, files and databases upload to OneDrive — and restore them from the same app. The Pi does all the work.

01How it works

The app never touches your data. It tells the Pi what to back up and where, and the Pi does the rest — so the backup keeps going when your phone sleeps or your laptop is closed.

PiKeep app

Phone or desktop. Picks sources, starts or schedules, shows progress.

SSH
commands only

Raspberry Pi

A small agent dumps the databases and runs restic as a background service.

restic over rclone
encrypted

OneDrive

Holds encrypted, deduplicated snapshots. Microsoft sees only ciphertext.

Runs without the app

A started backup is a systemd service on the Pi. Close the app, put the phone away — reopen it later and it shows exactly where things stand.

Encrypted before it leaves

restic encrypts and deduplicates everything on the Pi. After the first upload, each backup only sends what changed.

Consistent databases

PostgreSQL and MariaDB are dumped right before their files are backed up, and Nextcloud goes into maintenance mode for the duration — and always comes back out of it.

02Features

Everything a home server's backup needs, and nothing that phones home.

Automatic schedules

Daily, every second day, weekly or monthly, at a time you choose. If the Pi is off at that moment, the backup runs as soon as it is back.

Keep the last N — safely

Old snapshots are cleaned up automatically, but never because of a bad run: unreadable files, or a source that suddenly shrank to a fraction of its size, keep every older backup until you say so.

Live progress

Percent, bytes, files, time left and the file being uploaded, refreshed every few seconds — plus the full job log, one tap away.

Immich & Nextcloud ready

Sensible defaults for both, with their database hooks. Add any other folder on the Pi with a built-in folder browser.

Dry runs and checks

See what would be uploaded without changing anything, and optionally read back a random 5% of the stored data after a backup.

Snapshots at a glance

Every snapshot per source with its size, and a marker on the ones the next clean-up will remove.

Restore from the app

Browse any snapshot, pick files or folders, and restore them to a separate folder — or the whole snapshot back in place onto a replacement disk. It runs on the Pi, with live progress.

Alerts when it matters

A push notification through ntfy when a backup fails, the disk is missing or a source shrinks — sent by the Pi, so you hear about it without opening the app.

A dead disk stops backups

If the backup disk is not mounted the Pi refuses to run and deletes nothing; the app shows it on the first screen, and a restore guide walks you through the rebuild.

03Safe by construction

The agent on the Pi runs as root and takes input from the network, so it trusts nothing it is sent.

One command, nothing else

The sudoers rule allows exactly one program without a password. The app cannot run anything else as root on your Pi.

Paths are fenced in

Every folder is resolved — symlinks included — and must sit inside the roots you allow, /mnt/ssd by default. Every other value is checked against a strict pattern and passed as an argument, never to a shell.

A changed host key is a hard stop

The Pi's SSH key is remembered on first connect. If it ever changes, the app refuses to connect rather than warning and carrying on.

Secrets stay in the keychain

Your SSH password or key lives in the platform keychain. No account, no analytics, no server of ours in the middle.

04Set up your Pi

About fifteen minutes, once. Written for Raspberry Pi OS and Debian; the backup tools need a recent rclone.

  1. Install restic and a current rclone

    Debian's own rclone package is too old for OneDrive uploads, so take rclone from its project site.

    sudo apt install -y restic jq
sudo -v ; curl https://rclone.org/install.sh | sudo bash

  2. Connect OneDrive

    Create a remote called onedrive. On a Pi without a browser, rclone tells you to finish the sign-in with rclone authorize "onedrive" on your computer.

    sudo rclone config

  3. Create the backup password

    Every backup is encrypted with it. Save a copy in your password manager — without it, nothing can be restored.

    sudo sh -c 'umask 077; openssl rand -base64 32 > /root/.restic-pass'
sudo cat /root/.restic-pass

  4. Install the PiKeep agent

    Installs one script, its config and a sudoers rule for that script only, then prints a self-test.

    curl -LO https://github.com/__REPO__/releases/latest/download/PiKeep-pi-agent.tar.gz
tar xzf PiKeep-pi-agent.tar.gz && cd pikeep-pi-agent
sudo ./install.sh "$USER"

  5. Connect the app

    In Settings, enter the Pi's host name and your SSH login, then Save & test connection. Pick the onedrive remote, press Initialize repository once, and start with a dry run.

Opening an unsigned build

This build is not signed or notarised, so macOS refuses it on first open. Go to System Settings → Privacy & Security, find PiKeep under the warning, and click Open Anyway. Or, from a terminal:

xattr -d com.apple.quarantine /Applications/PiKeep.app

Not code-signed, so SmartScreen shows “Windows protected your PC”. Click More info → Run anyway. Unpack the zip anywhere and run pikeep.exe.
